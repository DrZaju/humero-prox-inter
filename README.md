# Húmero proximal interactivo

Visor interactivo del modelo de húmero proximal con tumor, basado en la Sketchfab Viewer API.

Modelo Sketchfab: [https://sketchfab.com/3d-models/humero-proximal-tumor-a8138671e7894bb9abd2950221cb03c2](https://sketchfab.com/3d-models/humero-proximal-nuevo-66e1a9ed57034f58b20f9efe1dc34187)

## Publicar en GitHub Pages
1. Crear un repositorio público `humero-proximal-interactivo`.
2. Subir `index.html` y `README.md` a la rama `main`.
3. En Settings → Pages, seleccionar Deploy from a branch, `main`, `/ (root)` y guardar.
4. Abrir `https://DrZaju.github.io/humero-proximal-interactivo/` cuando termine el despliegue.

Los controles usan los nombres `HumeroLatS`, `HumeroMedS` y `HumeroTumS`. Si Sketchfab los modificó, actualiza esos nombres en `index.html`.
